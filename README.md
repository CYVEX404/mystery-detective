# The Mystery Detective

The Mystery Detective is an interactive detective game where players solve mysterious cases by investigating suspects, discovering evidence, taking notes, and identifying the culprit

## Features
- 12 detective cases to solve
- Three difficulty levels: easy, medium, and hard
- Search cases by name
- Filter cases by difficulty
- Investigate suspects and discover evidence
- Take notes during investigations
- Accuse suspects and check your answers
- Track solved and unsolved cases
- Save progress automatically using Local Storage
- Reset investigation progress
- Responsive design

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Local Storage

## How to Play
1. Choose a detective case
2. Read the case description
3. Investigate the suspects
4. Discover and examine the available evidence
5. Take notes to organize your findings
6. Accuse the person you believe is responsible
